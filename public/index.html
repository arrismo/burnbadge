  1. Add these secrets to your GitHub repo: BURNBADGE_BASE_URL, BURNBADGE_BADGE_TOKEN, BURNBADGE_USAGE_TOKEN, OPENROUTER_API_KEY (or your provider key)
  2. Create .github/workflows/usage.yml with the workflow below
  3. Push to main — the badge will update automatically
