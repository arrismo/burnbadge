# Burnbar Publishing API

Burnbar is the local app that collects provider usage on your machine and publishes README badges through Burnbadge. Provider API keys, cookies, and local auth files stay on your computer. Burnbadge receives only normalized daily spend totals.

## Flow

```txt
Burnbar
  -> creates a Burnbadge project
  -> stores the private usage token locally
  -> uploads normalized daily usage
  -> gives you public README badge markdown
```

## 1. Create a project

```bash
curl -X POST https://burnbadge.mikaelmoise00.workers.dev/api/projects \
  -H 'content-type: application/json' \
  -d '{
    "provider": "openai",
    "name": "OpenAI README badge",
    "source": "burnbar"
  }'
```

Response:

```json
{
  "token": "public-badge-token",
  "badgeToken": "public-badge-token",
  "usageToken": "private-usage-token",
  "badgeUrl": "https://burnbadge.mikaelmoise00.workers.dev/api/badge/public-badge-token",
  "chartUrl": "https://burnbadge.mikaelmoise00.workers.dev/api/chart/public-badge-token",
  "usageUrl": "https://burnbadge.mikaelmoise00.workers.dev/api/usage/private-usage-token"
}
```

- `badgeToken` is public and safe for README badges and charts.
- `usageToken` is private and should only be stored locally by Burnbar.

## 2. Publish usage

```bash
curl -X POST \
  https://burnbadge.mikaelmoise00.workers.dev/api/usage/private-usage-token \
  -H 'content-type: application/json' \
  -d '{
    "provider": "openai",
    "usage": [
      {
        "date": "2026-05-21",
        "cost": 1.23,
        "breakdown": [
          { "model": "gpt-4.1", "cost": 0.8 },
          { "model": "o4-mini", "cost": 0.43 }
        ]
      }
    ]
  }'
```

Usage uploads replace the stored usage window for that project and update `lastUpdated`.

## 3. Read public status

Burnbar can verify public badge state without exposing the private usage token:

```bash
curl 'https://burnbadge.mikaelmoise00.workers.dev/api/status/public-badge-token?days=30'
```

Response:

```json
{
  "provider": "openai",
  "name": "OpenAI README badge",
  "source": "burnbar",
  "days": 30,
  "totalCost": 12.48,
  "todayCost": 0.31,
  "currency": "USD",
  "latestDate": "2026-05-21",
  "lastUpdated": "2026-05-21T18:00:00.000Z",
  "updatedAt": "2026-05-21T18:00:00.000Z",
  "badgeUrl": "https://burnbadge.mikaelmoise00.workers.dev/api/badge/public-badge-token?days=30",
  "shieldsUrl": "https://burnbadge.mikaelmoise00.workers.dev/api/shields/public-badge-token/image?days=30"
}
```

```md
![OpenAI spend](https://burnbadge.mikaelmoise00.workers.dev/api/shields/public-badge-token/image?days=30&logo=openai)

![OpenAI spend chart](https://burnbadge.mikaelmoise00.workers.dev/api/chart/public-badge-token?days=30)
```
